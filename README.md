An original chess engine in 4 KB of Python: negamax alpha-beta search with quiescence, a transposition table, PVS, LMR, null-move pruning, killer and history move ordering, and piece-square-table evaluation, playing the make.fun gauntlet through the env at MAKEFUN_ENV_URL under a fixed node budget (never a clock).

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> MAKEFUN_PROMPT_FILE=/input/prompt.txt python3 main.py
```
